# Quick Start - Push to GitHub

## 🚀 3 Simple Steps to Push Your Code

### Step 1: Create GitHub Repository
1. Go to https://github.com/new
2. Repository name: `fixitfast-website`
3. **DO NOT** check any initialization options
4. Click "Create repository"

### Step 2: Connect to GitHub
Copy and run these commands (replace YOUR-USERNAME):

```bash
cd /d/fixitfast-website
git remote add origin https://github.com/YOUR-USERNAME/fixitfast-website.git
git push -u origin master
```

### Step 3: Enter Credentials
- **Username**: Your GitHub username
- **Password**: Your Personal Access Token (NOT your password!)

**Get Token**: https://github.com/settings/tokens → Generate new token → Select `repo` scope
