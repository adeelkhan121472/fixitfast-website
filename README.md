# Fix It Fast Appliances - SEO Optimized Website

Professional appliance repair service website with comprehensive SEO optimization.

## 🌟 Features

- **Fully SEO Optimized** - Complete meta tags, Schema.org markup, and structured data
- **Responsive Design** - Mobile-friendly and accessible
- **5 Pages** - Home, About, Services, Cities, Contact
- **Schema.org Markup** - LocalBusiness, Services, FAQ, Breadcrumbs
- **Social Media Ready** - Open Graph and Twitter Card tags
- **Performance Optimized** - GZIP compression, browser caching

## 📋 Pages

1. **Home (index.html)** - Hero section, services overview, benefits, service areas
2. **About (about.html)** - Company history, mission, values, team stats
3. **Services (services.html)** - Detailed service descriptions for all appliances
4. **Service Areas (cities.html)** - 25+ cities served with search functionality
5. **Contact (contact.html)** - Contact form, business hours, FAQs

## 🎯 SEO Features

### Meta Tags
- Optimized title tags with keywords
- Compelling meta descriptions (150-160 chars)
- Meta keywords for each page
- Canonical URLs
- Robots meta tags
- Geographic targeting

### Schema.org Structured Data
- **LocalBusiness** - Complete business information
- **Organization** - Brand and contact details
- **Service** - Individual service listings
- **FAQPage** - Frequently asked questions
- **BreadcrumbList** - Navigation hierarchy
- **AggregateRating** - Customer reviews display

### Social Media Optimization
- Open Graph tags (Facebook, LinkedIn)
- Twitter Card metadata
- Social sharing images

### Technical SEO
- `robots.txt` - Search engine crawling rules
- `sitemap.xml` - Complete site structure
- `.htaccess` - Performance and security optimization

## 🚀 Getting Started

### Prerequisites
- Web server (Apache, Nginx, or local development server)
- Modern web browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/fixitfast-website.git
cd fixitfast-website
```

2. Open in a web server or use a local development server:
```bash
# Using Python
python -m http.server 8000

# Using PHP
php -S localhost:8000

# Using Node.js (http-server)
npx http-server
```

3. Open your browser and navigate to:
```
http://localhost:8000
```
